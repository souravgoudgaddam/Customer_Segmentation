# 🧩 Customer Segmentation Using K-Means Clustering

## 📌 Project Overview
This project focuses on **customer segmentation** using **unsupervised machine learning techniques**.

The goal is to group customers into meaningful clusters based on demographic and behavioral attributes such as **Age**, **Annual Income**, and **Spending Score**. This helps businesses better understand customer behavior and target them effectively.

---

## 🎯 Objectives
- Preprocess customer data for clustering  
- Reduce dimensionality using PCA for visualization  
- Identify the optimal number of clusters using the Elbow Method  
- Segment customers using K-Means clustering  
- Visualize customer segments in 2D space  

---

## 📂 Dataset
**File Name:** `Mall_Customers.csv`

### Features
- **CustomerID** – Unique customer identifier  
- **Genre** – Gender of the customer (Male/Female)  
- **Age** – Age of the customer  
- **Annual Income (k$)** – Annual income in thousands  
- **Spending Score (1–100)** – Score assigned based on customer behavior  

---

## 🛠️ Libraries Used
- pandas  
- numpy  
- matplotlib  
- seaborn  
- scikit-learn  

---

## 🔄 Project Workflow
1. Load and explore the dataset  
2. Encode categorical variables  
3. Remove irrelevant features  
4. Scale features using StandardScaler  
5. Apply PCA for dimensionality reduction  
6. Determine optimal clusters using the Elbow Method  
7. Perform K-Means clustering  
8. Visualize customer segments  

---

## 📈 Results
- Customers are grouped into distinct clusters  
- Each cluster represents a unique customer segment  
- PCA visualization clearly shows separation between clusters
